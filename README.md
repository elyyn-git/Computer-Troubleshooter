
# Computer Troubleshooter

Sistem diagnosis dan troubleshooting komputer berbasis website.

## Deskripsi
Computer Troubleshooter merupakan aplikasi berbasis website yang membantu pengguna mengidentifikasi masalah pada komputer atau laptop dan memberikan solusi berdasarkan hasil diagnosis.

## Teknologi
- C++
- Crow Framework
- HTML
- CSS
- JavaScript
- CSV
- JSON

## Fitur
- Login Guest dan Admin
- Diagnosis masalah komputer
- Hasil diagnosis dan solusi
- Riwayat diagnosis
- Pengelolaan pertanyaan oleh Admin
- Statistik diagnosis

## Struktur Project
- `backend/` - Program C++ dan API
- `frontend/` - Tampilan website
- `database/` - Penyimpanan data CSV
- `docs/` - Dokumentasi project
